# HiveConnect
A bot made using gophertunnel.
It was meant to be used to connect to hive and make private "games" for competitive matchmaking; however, the user who comissioned it no longer needs it and allowed me to make it open source.

The project remains unfinished; however, most of the core is intact.

Features of the core:
- Bypass Hive Anti VPN
- API system to store currently used bots, bot status and etc (On my personal version, the API system was linked to a discord bot)
- Running commands ingame, as well as a packet response system which allows the bot to do functions one at a time (properly and efficiently)
- Packet logger

Features missing
- Kill Tracking
- Death Tracking
- Bed Break Tracking

This was a passion project which I used to have an attempt at learning golang. It is in no way properly built for commercialised usage.

One of my friends aShanki has a new and improved version which works with the same core and principle.
