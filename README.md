# HiveConnect
A bot made using gophertunnel.
It was meant to be used to connect to hive and make private "games" for competitive matchmaking; however, the user who comissioned it no longer needs it and allowed me to make it open source.

The project remains unfinished; however, most of the core is intact.

Features missing
- Discord to Hive Connection
- Kill Tracking
- Death Tracking
- Bed Break Tracking


One of my friends aShanki has a new and improved version which works with the same core and principle.
